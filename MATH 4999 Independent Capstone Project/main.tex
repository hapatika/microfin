\subsubsection{\textbf{Time series analysis}}
The goal of time series analysis is to describe the probabilistic structure of the stochastic process $\{X_t\}$ by statistical methods. We do this by fitting various models to the moment functions of these random variables. The conditional moments of the time series are analogous to the conditional moments of the martingale based on the information measure.
The autocorrelation function (ACF) of a time series is defined as \[\rho(s,t) = \text{Corr}(X
_s, X_t) = \frac{\text{Cov}(X_s, X_t)}{\sqrt{\text{Var}(X_s)\text{Var}(X_t)}}= \frac{\text{E}[(X_s - \mu_s)(X_t - \mu_t)]}{\sqrt{\text{Var}(X_s)\text{Var}(X_t)}}  \]
We also consider the partial autocorrelation function (PACF) which allows us to only consider the direct effects of the lagged variables. This allows us to get a pure regression on the underlying variables.

\begin{theorem}
    \textbf{Wold Representation Theorem} Any zero-mean covariance stationary time series $\{X_t\}$ can be decomposed as $X_t = V_t + S_t$ where 
    \begin{itemize}
        \itemsep 1px
        \item $\{V_t\}$ is a linear combination of past values of $V_t$ with constant coefficients.
        \item $S_t$ is an infinite moving average process. $S_t = \sum_{i=0}^\infty \psi_i \eta_{t-i}$, where $\psi_0 = 1;  \sum_{i=0}^\infty \psi_i^2 < \infty $
        \item $\{\eta_t\}$ is linearly unpredictable white noise.
    \end{itemize}
\end{theorem}
